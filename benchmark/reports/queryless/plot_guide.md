# How to read this report

Every method on this page receives only the source. Do not compare its scores with the other report.

- **Task success by source location**: each curve uses only one 40-case source-location group. A result succeeds only when needed source text survives, prohibited text is absent, and the output stays within its limit.
- **Why there is no single score**: the report does not average away differences caused by where needed text appears.
